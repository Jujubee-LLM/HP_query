# 题集扩充方案（哈利波特小说场景）

目标：覆盖“人物/事件/设定/术语/关系/情节节点”等多类型问题，保证有可追溯的 `gold_chunk_ids`。

## 一、题型结构（建议配比）
1) **事实型**（40%）  
   - 人物/物品/概念的定义、作者、地点、时间点  
   - 例：某教科书作者是谁？某组织是什么？

2) **情节型**（30%）  
   - 具体场景或事件的直接事实  
   - 例：谁说了什么、谁做了什么、某场景发生在哪里

3) **多字段型**（20%）  
   - 同一对象多个属性  
   - 例：某人“出身/职业/身份”等

4) **列表型**（10%）  
   - “哪些/列出/有哪些”  
   - 需明确判定标准，并要求每个条目给出关键描写或情节

## 二、覆盖面建议
- **人物**：哈利、赫敏、罗恩、邓布利多、斯内普、伏地魔等  
- **组织**：凤凰社、食死徒、魔法部  
- **地点**：霍格沃茨、蜘蛛尾巷、阿兹卡班等  
- **书籍/术语**：魔法防御理论、怪兽及其产地、魂器等  
- **剧情节点**：入学、分院、舞会、决斗、审判等

## 三、生成 gold_chunk_ids 的流程
1) 先在 Web UI 查询问题  
2) 记录命中的 `chunk_id`  
3) 写入 `scripts/questions.jsonl` 的 `gold_chunk_ids`

## 四、扩展示例模板
```json
{"id":"qXX","question":"……？","gold_chunk_ids":["p123_c0"],"k":8,"mode":"retrieve_only"}
```

## 五、推荐新增方向（可直接扩充）
- “首次出现”类条目：可稳定对应到固定 chunk  
- “术语解释/来源/作者”类：稳定且易标注  
- “某角色说/做了什么”类：适合情节型验证
